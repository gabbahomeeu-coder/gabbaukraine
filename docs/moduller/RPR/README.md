# RPR · Raporlama

> Tüm modüllerden veri toplayıp tek yerde gösterir.

- **Katman:** İş katmanı
- **Durum:** kapatılabilir
- **Bağımlı olduğu modüller:** SIP, ANL

## Alt modüller

| Künye | Ad | Sorumluluk |
|---|---|---|
| `RPR-01` | Satış | Ciro, sipariş adedi, ortalama sepet. |
| `RPR-02` | Trafik | Ziyaretçi, kaynak ve dönüşüm oranı. |
| `RPR-03` | Reklam geri dönüşü | Harcama ve getiri karşılaştırması. |
| `RPR-04` | Stok & tedarikçi | Tükenen ürünler, tedarik süreleri. |
| `RPR-05` | Dışa aktarma | Raporların tablo veya PDF çıktısı. |
| `RPR-06` | Kârlılık | Maliyet ve satış farkı — hangi ürün gerçekten kazandırıyor. |
