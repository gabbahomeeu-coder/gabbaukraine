# TLG · Telegram

> Bot üzerinden yönetici ve müşteri bildirimleri.

- **Katman:** İş katmanı
- **Durum:** kapatılabilir
- **Bağımlı olduğu modüller:** API

## Alt modüller

| Künye | Ad | Sorumluluk |
|---|---|---|
| `TLG-01` | Bot & kanal | Bot bağlantısı ve hedef sohbetler. |
| `TLG-02` | Yönetici bildirimi | Sipariş, talep ve kurala uyan ziyaretler yöneticiye düşer. |
| `TLG-03` | Müşteri bildirimi | Sipariş durumu ve kargo bilgisi müşteriye. |
| `TLG-04` | Komutlar | Telegram üzerinden hızlı sorgu ve işlem. |
